## Quick workflow

1. **Create a project** and give it a name (e.g. engagement code).
2. **Upload ROE** — paste or upload IPs and hostnames that are in scope.
3. **Use the checklist** — run Recon, Nmap, Enumeration, Web host, etc. as needed.
4. **Review Hosts** — see aggregated hosts, ports, screenshots, and findings.
5. **Nessus** (optional) — create/launch/import Nessus scans and view vulns per host.
6. **Reporting** — download workpapers (scan outputs) as a zip.
